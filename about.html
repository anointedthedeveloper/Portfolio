Background

I am a full stack developer and software engineer from Nigeria. I started programming in 2019, teaching myself computer science fundamentals before building for clients and publishing my work on GitHub.

Day to day that means React and TypeScript interfaces, Node.js and Python services, and the databases behind them, plus the occasional desktop app in C# or Android app in Kotlin. I am most interested in real-time systems, access control done properly at the database, and tools that remove repetitive work.

Alongside Anobyte Technologies, I build and maintain software for Peter Harvard International Schools. I also publish on Dev.to.

How I build

  1. 01Own the whole path.Schema, API, interface and deployment. Most bugs live at the seams, so I work on both sides of them.
  2. 02Put rules where they cannot be bypassed.RepoRoom enforces row-level security in Postgres; the exam system persists progress on the server so a restart loses nothing.
  3. 03Automate the repetitive part.github-orbit runs on a schedule and the Nexus CLI scaffolds a project in one command.
  4. 04Respect limits.Rate limits, bot filters and cooldowns are part of the design, not an afterthought.
